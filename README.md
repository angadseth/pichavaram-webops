# Web Ops · Pichavaram House

Recruitment form for the Pichavaram House Web Ops team (IIT Madras BS). One question per card, with a mangrove drawn in ink that grows as you answer. Drag the tree to turn it, tap the water for a ripple.

Answers go to a Google Form owned by the house Web Admin account. Its action URL and entry ids live in `config.js`.

Plain HTML, CSS and JS, plus three.js. No build step. Run it with any static server:

```sh
python -m http.server 8811
```

`mail.html` is the announcement mail body.
